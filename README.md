# Itzfizz Scroll-Driven Hero

A scroll-driven hero section built with:

- Next.js
- React
- JavaScript
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger

## Features

- Animated "WELCOME ITZFIZZ" headline
- Statistics count-up animation
- Scroll-driven car movement
- Car wheel rotation
- Moving clouds
- Moving sun
- Beach, water and sand scene
- Road with animated visual markings
- Responsive mobile layout
- Final "FIZZ ON." transition

## Run locally

```bash
npm install
npm run dev
```

Open:

http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Notes

The main animation is controlled by GSAP ScrollTrigger and is tied to scroll progress using `scrub`.
